# Instant LiDAR project page

Static research project page prepared for `https://kangx326.github.io/Instant-LiDAR/`.

Open `index.html` for a local preview, or serve this folder with `python3 -m http.server 8000` to test video captions and browser behavior.

The site has no build step, tracking scripts, external fonts, or runtime dependencies. Keep the directory structure intact when copying it into the GitHub Pages repository.

## Content

- The supplied Instant LiDAR manuscript and its tables provide the scientific claims and numerical results.
- `assets/workflow.mp4` contains the full 66-second user-supplied Cosmos × Instant LiDAR demonstration at 1080p, 30 fps, with narration. No scenes were cut or sped up.
- `assets/reconstruction.mp4` is the previously approved comparison with NuRec / Instant LiDAR / Ground Truth titles.
- Reconstruction time and detection values are stored in `app.js`. All comparisons keep the paper's dataset and query-setting distinctions.
- The 51-second demonstration case and 66-second Waymo average are explicitly distinguished.

Design structure references https://lastbasket.github.io/LiDAR-EVS_page/ . The markup and styles are original to this page.
